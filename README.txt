Paulas Garten


Übersicht

Paulas Garten ist ein statisches Webprojekt, das vollständig mit HTML und CSS umgesetzt wurde.
Das Layout wurde speziell für die Darstellung auf einem iPad Pro (1366x1024) entwickelt und sollte ausschließlich über die Geräteansicht („Device Toolbar“) in Google Chrome betrachtet werden.

Voraussetzungen

Für die korrekte Anzeige des Projekts werden folgende Punkte benötigt:
	•	Google Chrome (aktuelle Version)
	•	Keine zusätzlichen Installationen oder Erweiterungen
	•	Lokale Projektdateien inklusive:
	•	HTML-Dateien
	•	CSS-Dateien
	•	Bildmaterial im Ordner /images

Projekt öffnen
	1.	Bitte öffnen Sie den bereitgestellten Projektordner.
	2.	Öffnen Sie anschließend die Datei index.html in Google Chrome
		(Rechtsklick → Öffnen mit → Google Chrome).

Darstellung im iPad-Pro-Format (erforderlich)

Da das Projekt ausschließlich für die Anzeige auf einem iPad Pro optimiert ist, wird die folgende Einstellung empfohlen:
	1.	Öffnen Sie die Datei index.html in Google Chrome.
	2.	Öffnen Sie die Entwicklertools:
	•	Taste F12, oder
	•	Rechtsklick → Untersuchen
	3.	Aktivieren Sie die Geräteansicht:
	•	Symbol „Geräte-Toolbar umschalten“ (kleines Smartphone-/Tablet-Symbol oben 			links).
	4.	Wählen Sie im Geräte-Dropdown iPad Pro(Querformat) aus.
	•	Falls das Gerät nicht aufgeführt wird:
	•	Edit / Bearbeiten → Add device → iPad Pro hinzufügen.
	5.	Bitte überprüfen Sie darüber hinaus:
	•	Zoom: 100 %
	•	Ausrichtung: Hoch- oder Querformat entsprechend den Projektanforderungen.

Erst in dieser Einstellung wird die Seite korrekt und im vorgesehenen Format dargestellt.
